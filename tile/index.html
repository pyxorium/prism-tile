Prism
This page doesn't save Prism games.

Object of game

Fill the board with dice selected from the pool, one at a time.

How to play

Cast the dice in the pool, and pick one die.

Lit spaces on the board show permissible plays for the selected die.

Tap a lit space on the board to place the die.

Dice that share an edge can't match color or number.

Marked spaces take only one color, or one number.

Start on the edge; after that, each die must touch one already placed (corners count).

If no die can go anywhere, the pool is cast again; those dice still count.

The game ends when the board is full or after 24 draws.

Score: +1 per filled space, −1 per empty one, +3 for each row with all four colors (rainbow bonus).

Daily: today's dice are the same for everyone. Free play: new dice every game.
